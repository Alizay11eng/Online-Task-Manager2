 FocusFlow – Productivity Dashboard

FocusFlow is a front-end web application designed to help users manage their tasks, projects, and focus sessions efficiently. It provides an intuitive dashboard to track daily progress, organize tasks by priority and projects, and maintain focus with a built-in timer system. This project is ideal for anyone looking to improve personal productivity and task management.
 Features

- Task Management: Add, edit, and delete tasks with options for priority, deadline, notes, and project assignment.
- Project Organization: Group tasks under different projects for better management and tracking.
- Focus Mode: Includes Start, Pause, Reset, and Set functionality for dedicated focus sessions.
- Dashboard Statistics: Provides clear statistics including Due Today, Completed, Total Tasks, Today's Focus, and Pending tasks.
- Settings Page: Customize user profile, default focus time, daily goals, and theme preference.
- Local Storage: All data is stored locally in the browser, ensuring persistence without a backend server.

Technologies Used:

- HTML5: Structure and layout of the application.
- CSS3: Styling, theming, and layout design.
- JavaScriptDynamic task management, Focus Mode timer, and localStorage functionality.
- Local Storage: For saving tasks and project data locally.
